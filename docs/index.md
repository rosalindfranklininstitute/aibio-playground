# Introduction
## Bioimage Analysis Playground: The novice's gateway to quantitative biological image analysis 

This project aims to provide a gateway for newcomers to learn the language of
bioimage analysis, play with image processing techniques using their own data,
and be signposted toward relevant tools and communities to continue learning and
analysis.

The 'Bioimage Analysis Playground' is a Marmio notebook application that uses
calls to a local LLM (`gemma4:26b`) to help you construct an image anaylsis
pipeline, drawing on a curated library of image analysis functions.

This documentation covers using the application, if you are a newcommer that
already have access to a running instance, as well as a guide for system
administrators who want to deploy the application.
